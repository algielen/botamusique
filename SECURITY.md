# Security Policy

Security maintenance is best-effort: no version has guaranteed security support, and we cannot promise
response times or fixes. Use this software at your own risk.

## Reporting a vulnerability

Please report security issues through [GitHub Issues](https://github.com/algielen/botamusique/issues).
Include the affected version, a description of the issue, and steps to reproduce
it. Do not include passwords, tokens, or other sensitive information.
